# Markdownの文書構造adapter

[English](README.md)

CommonMarkと現行document-structureを使い、Markdownをboundedなnode/relationへ整理します。source reference、入力上限、truncated状態を保持し、製品上の意味や権限は決めません。

公開importは@zixcel/document-markdownのparseMarkdownSurfaceです。正式registry依存と開発workspaceを分け、[playground](../../playground/parse-documents/README.ja.md)でTGZの型・実行・旧形式拒否を確認します。LICENSE/NOTICEを保持します。
